3. Face Detection (YuNet)

YuNet is a lightweight CNN optimized for real-time face detection. It outputs bounding boxes and 5 facial landmarks per face.

Algorithm Steps
  1. Preprocessing: Resize input to 320×320
  2. CNN Forward Pass: Multi-scale feature pyramid
  3. Confidence Filter: Keep detections > 0.7
  4. NMS: Remove overlaps (IoU threshold: 0.3)
  5. Output: Bounding box + 5 landmarks
Parameter Value
Input Size 320 × 320 pixels
Score Threshold 0.7
NMS Threshold 0.3
Landmarks Eyes, Nose, Mouth corners

YuNet Output Format

# Each detection contains 15 values:
face = [
    x, y, width, height,  # Bounding box
    right_eye_x, right_eye_y,
    left_eye_x, left_eye_y,
    nose_x, nose_y,
    right_mouth_x, right_mouth_y,
    left_mouth_x, left_mouth_y,
    confidence_score  # 0.0 to 1.0
]

4. Face Recognition (SFace)

Embedding Extraction

def compute_embedding(face_image):
    # Resize to model input size
    face = cv2.resize(face_image, (112, 112))
    
    # Extract 128D feature vector
    embedding = recognizer.feature(face)
    
    # L2 Normalize for cosine similarity
    embedding = embedding / np.linalg.norm(embedding)
    
    return embedding  # Shape: (128,)

Recognition Algorithm

def recognize(query_embedding):
    # Vectorized comparison with ALL students
    # embedding_matrix: (N_students, 128)
    similarities = np.dot(
        embedding_matrix,
        query_embedding
    )
    
    # Find best match
    best_idx = np.argmax(similarities)
    best_score = similarities[best_idx]
    
    # Threshold check
    if best_score > 0.40:
        return students[best_idx]
    return None  # Unknown

Similarity Distribution

Cosine Similarity

Similarity = A · B = Σ(Aᵢ × Bᵢ)
Score Meaning
1.0 Identical (same person)
> 0.4 Above threshold → MATCH
0.2 - 0.4 Similar but uncertain
< 0.2 Different person

5. Behavior Detection (YOLOv8-Pose)

YOLOv8-Pose detects 17 body keypoints per person. We analyze head-shoulder geometry to classify behavior.

Classification Rules
if nose_y > shoulder_mid_y + 20:
    return "sleeping"  # Head dropped

elif head_offset / shoulder_width > 0.4:
    return "distracted"  # Looking away

elif hands_below_shoulders:
    return "studying"  # Writing

else:
    return "focused"

9. Interview Questions

Architecture

Q: Why FastAPI over Flask?
Native async/await, auto-documentation, type hints, 2-3x faster.

Q: Why WebSocket vs HTTP?
Persistent connection, bidirectional, low latency (~180ms).

Q: Why MongoDB?
Native array storage for embeddings, flexible schema, horizontal scaling.

AI & Computer Vision

Q: What is a face embedding?
128D vector representing facial features. Similar faces = similar vectors.

Q: What is NMS?
Non-Max Suppression removes duplicate overlapping detections.

Q: How is behavior detected?
YOLOv8-pose keypoints → head-shoulder geometry → classify state.
